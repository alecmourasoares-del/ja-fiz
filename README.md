# JÁ FIZ?

Protótipo do aplicativo JÁ FIZ?, do trabalho de Projeto do Produto e do Processo (UFPI). É um app de checklists que avisa no horário e guarda a confirmação de cada item com data e hora.

Funciona no navegador do celular e pode ser instalado na tela inicial (PWA). Os dados ficam só no aparelho de quem usa.
